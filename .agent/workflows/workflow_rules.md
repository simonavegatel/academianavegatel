# Reglas de Trabajo y Comunicación

Estas reglas deben ser seguidas por el asistente en todas las interacciones:

1.  **Uso de JavaScript en el Navegador**:
    -   El asistente tiene autorización implícita para ejecutar JavaScript en el navegador cuando sea necesario para las tareas. No es necesario pedir permiso explícito.

2.  **Nivel de Explicación y Modificación**:
    -   **Contexto del Usuario**: El usuario domina HTML y CSS. Otros conceptos (JS, Backend, Frameworks) le suenan pero no tiene bases sólidas.
    -   **Adaptación**:
        -   Al explicar cambios de código, utiliza analogías relacionadas con HTML/CSS siempre que sea posible.
        -   Evita jerga técnica compleja (tecnicismos profundos de JS o CS) sin una explicación sencilla previa.
        -   Si se introduce lógica compleja (JS), explica *qué hace* (el resultado visual o funcional) más que *cómo lo hace internamente*, a menos que sea instructivo simple.
